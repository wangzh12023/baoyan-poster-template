# 配色一览 · Palettes

54 款配色的全部色值（sRGB 十六进制）。所有颜色都在 OKLCH 色彩空间里定义，源码见 [`posterkit/palettes.py`](../posterkit/palettes.py)。

| 列 | 含义 |
|---|---|
| 墨色 ink | 主标题、姓名、底栏内容 |
| 正文 body | 院校、英文副标题、场次时间 |
| 注释 muted | 嘉宾时间、小标签、注释 |
| 强调 accent | 分享主题、场次编号、星期、特邀标签 |
| 点缀 pop | 年份横线、场次末尾圆点 |
| 细线 hair | 嘉宾之间的分隔线 |
| 背景 bg | 背景渐变的三个色标 |
